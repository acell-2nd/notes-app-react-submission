# Aplikasi Catatan (React + react-router-dom)

Fitur: daftar catatan aktif, halaman arsip, detail catatan (`/notes/:id`),
tambah catatan (`/notes/new`, isi catatan memakai `contentEditable`),
hapus, arsip/aktifkan, dan pencarian berdasarkan judul.

## Menjalankan
```
npm install
npm run dev
```

## Build
```
npm run build
```
